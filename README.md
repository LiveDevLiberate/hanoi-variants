# 汉诺塔变体 · 状态图展示

纯静态网站，用 D3/SVG 交互式展示 7 种汉诺塔变体的状态切换图（分形图）。
深色学术风格：纯黑背景、白色字体、金色节点、白色边。

## 运行

直接用浏览器打开 `index.html`（无需服务器），或：

```bash
cd hanoi-variants
python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 变体

| 变体 | 说明 | 状态图 |
|---|---|---|
| 经典 3 柱 | 三柱 n 盘，Sierpinski 三角 | 3 叉分形 |
| 相同碟片 | 每级 N 个相同盘 | C(N+2,2) 叉分形 |
| 单向循环 | 只能 A→B→C→A | 有向图（箭头） |
| 线性相邻 | 只能移到相邻柱 | 折线分形 |
| 4 柱 | 四柱四面体 | 2D 投影 |
| 磁铁 | 同极不能相邻 | 受限子图 |
| 禁止状态 | 最大盘禁放中柱 | 挖洞子图 |

## 交互

- 七个变体垂直排列在同一页面，滚动浏览
- 每个变体独立参数滑块（盘数/碟数/等级数），实时更新
- 标签开关、最短路径高亮开关（每变体独立）
- 底部参考文献区（汉诺塔图论经典文献）

## 测试

```bash
node test/test_core.js
node test/test_variants.js
```

测试数据已用 Wolfram 独立验证（状态数/边数）：
- 经典 3盘: 27 状态 39 边
- 相同碟片 N=2,nl=2: 36 状态 63 边
- 单向 n=3: 27 状态 39 有向边
- 线性 n=3: 27 状态 26 边
- 磁铁 n=3: 21 状态 24 边（过滤同极相邻非法状态）
- 禁止 n=3: 18 状态 25 边

# 汉诺塔变体状态图展示网站 — 设计文档

- **日期**: 2026-08-26
- **状态**: 待用户审阅
- **项目路径**: `~/hanoi-variants/`

## 1. 目标

构建一个纯静态网站，以**状态切换图**（分形图）为核心，交互式展示 7 种汉诺塔变体：
经典 3 柱、相同碟片、单向循环、线性相邻、4 柱、磁铁、禁止状态。

每种变体通过参数滑块探索其状态图结构，并附状态数/边数公式与相关论文引用。

## 2. 技术栈

| 项 | 选择 | 理由 |
|---|---|---|
| 构建方式 | **纯静态**（无构建步骤） | 浏览器直接打开 `index.html`，零依赖 |
| 语言 | 原生 JS (ES Modules) | 无框架，轻量 |
| 渲染 | **D3.js v7**（本地 `lib/d3.v7.min.js`） | SVG 操作、力导向/布局工具 |
| 2D 渲染 | SVG（D3 操作） | 清晰、可缩放、节点标签易处理 |
| 4柱变体 | **D3 2D 投影**（四面体正交投影） | 技术栈统一，无 WebGL 依赖 |
| 主题 | 深色（黑底白边金点） | 延续已有 GIF/MP4 的视觉风格 |

## 4. 数据模型

### 4.1 状态编码（所有变体共享）

- 状态 = 长度 `n` 的数组，`state[i]` = 盘 i 所在柱（0 基索引，柱编号 0..p-1）
- `n` = 盘数，`p` = 柱数（默认 3，4 柱变体 p=4）
- 相同碟片变体：状态 = `nl` 个等级的分布数组，每级 = 长度 `N` 的排序数组（每盘所在柱）

### 4.2 变体注册器接口

每个变体导出一个对象：

```js
{
  id: 'classic',
  name: '经典 3 柱',
  params: [ { key: 'n', label: '盘数', min: 1, max: 6, default: 3 } ],
  buildStates(params) -> states[],        // 枚举所有合法状态
  buildEdges(states, params) -> edges[], // 每边 [i, j] 为状态索引对
  layout(states, params) -> coords[],    // 每状态 [x, y]（barycentric / 四面体投影 / 多叉递归）
  formula(params) -> { states, edges },  // 状态数/边数公式（字符串，数学记号）
  shortestPathLabel: ['000', '222'],     // 最短路径起终点（可选）
}
```

## 5. 7 个变体设计

| # | 变体 | 状态图结构 | 布局 | 参数 |
|---|---|---|---|---|
| 1 | 经典 3 柱 | Sierpinski 三角（无向） | barycentric | 盘数 n |
| 2 | 相同碟片 | C(N+2,2) 叉递归分形 | 多叉 barycentric | 碟数 N、等级 nl |
| 3 | 单向循环 | 有向 Sierpinski（箭头） | barycentric | 盘数 n |
| 4 | 线性相邻 | 非三角折线分形 | 线性 barycentric | 盘数 n |
| 5 | 4 柱 | 四面体 2D 投影 | 四面体正交投影 | 盘数 n |
| 6 | 磁铁 | 受限子图 | barycentric | 盘数 n |
| 7 | 禁止状态 | 挖洞子图 | barycentric | 盘数 n |

### 5.1 移动判定差异

- **经典**：任意柱 → 任意柱，目标柱顶部盘更大或空
- **相同碟片**：每级 N 个相同盘，同大小盘可互叠，分布去重
- **单向循环**：目标柱 = (源柱 + 1) mod p（A→B→C→A）
- **线性相邻**：目标柱 = 源柱 ± 1（仅相邻柱）
- **4 柱**：任意柱 → 任意柱（p=4）
- **磁铁**：同大小盘不能相邻堆叠（异极约束）
- **禁止状态**：黑名单状态（如最大盘禁放中柱）从状态集剔除

## 6. 渲染设计（render.js）

- **SVG 容器**：`<svg>` 全图区，responsive 缩放
- **边**：`<line>` 灰色细线（白边，深色主题）
- **有向边**（单向变体）：`<line>` + `<marker>` 箭头（金色）
- **节点**：`<circle>` 金色填充
- **标签**：`<text>` 白色，节点上方偏移；状态 > 800 时自动隐藏
- **最短路径**：`000→222` 的路径边用红色/高亮色加粗（Dijkstra/BFS 计算）
- **交互**：悬停节点显示状态详情 tooltip（该状态盘分布含义）

## 7. UI 设计

- **布局**：左侧固定导航（7 变体列表 + 图标），右侧主图区，底部论文引用区
- **每页控件**：
  - 参数滑块（根据变体动态生成）
  - 标签开关（checkbox）
  - 最短路径高亮开关（checkbox）
  - 状态数/边数实时显示 + 公式
- **深色主题（纯文字极简 · 学术风）**：背景纯黑 `#000000`，边白，节点金 `#ffd700`，文字白；衬线字体（Georgia/宋体），无卡片/圆角/阴影/渐变/emoji，排版疏朗、只有文字与线条

## 9. 数据流

```
用户拖动滑块 → app.js 更新 params → variants.js 生成 states/edges/coords
→ render.js 更新 SVG（增量 diff 或全量重绘）→ 状态数/边数/公式更新
```

## 10. 错误处理

- 状态数 > 5000：显示提示"状态过多"，不渲染（避免卡死）
- 公式计算失败：显示"公式未推导"占位
- 布局 NaN：跳过该节点并 console.warn

## 11. 测试

- 手动验证：每个变体各参数组合，状态数/边数与 Wolfram 已验证数据核对
  （经典 3盘27态39边、相同碟片 m=2nl=2 36态63边 等）
- 浏览器 console 无报错
